Plateforme pour la fédération camerounaise des de formation professionel(FECACFOP)

Description du projet

Cette application desktop permet de gérer efficacement les stagiaires au sein de HGOPED. Elle inclut des fonctionnalités comme l'enregistrement, le suivi et la génération de rapports.

Fonctionnalités principales

  • Ajout, modification et suppression des stagiaires
  • Gestion des présences et absences
  • Export des données en PDF
  • Interface intuitive et ergonomique

Technologies utilisées

Java MySQL Java Swing
