Application Desktop de Gestion de Stock

Description du projet

Cette application desktop permet de gérer efficacement le stock d’une entreprise. Elle inclut l’ajout, la modification et la suppression de produits, ainsi que le suivi des entrées et sorties.

Fonctionnalités principales

  • Ajout, modification et suppression de produits
  • Gestion des entrées et sorties de stock
  • Alertes pour produits faibles en quantité
  • Interface intuitive et ergonomique

Technologies utilisées

Java MySQL Java Swing
